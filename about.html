Registro de Cambios

v0.9.X - Funcionalidades definidas para cuestiones de desarrollo (DEV).

v1.0.X - Primera versión terminada para motivos de desarrollo preliminar (DEV).

v1.0.1 - Plataforma finalizada. Se añadieron nuevos cambios en cuanto a la funcionalidad del dashboard para mejorar su funcionamiento (V1.0). Se integró un combo en el módulo "Nuevo préstamo" para usuarios Prestamistas, facilitando la selección de carreras establecidas (DEV).

v1.1.1 - Se incorporó funcionalidades de seguridad para contraseñas. Estas se cifrarán desde la instalación, y se integraron políticas de seguridad en el módulo "Administrador de usuarios" para usuarios Administradores, evitando que se presenten en texto plano. Se añadieron validaciones extra (internas) al momento de generar nuevos préstamos. Ahora se almacena el nombre del prestamista quien registra devoluciones para su posterior consulta en vales y detalles de cada préstamo individual. Se añadieron nuevos campos en el módulo "Nuevo préstamo" para especificar Area, Unidad y Responsable, y a su vez se añadió una nueva pestaña para Administrador llamada "Configuración de variables", que permite personalizar la procedencia de los deudores y el laboratorio donde se implementará esta plataforma, y se empleará para la emisión de vales. Se corrigieron errores menores de funcionalidad interna (ESTABLE).

v1.1.2 - Se incorporó la funcionalidad de visualización de imágenes de los bienes, y la carga de los mismos, los cuales se pueden consultar por registro. Se incorporó la posibilidad de editar los detalles del bien de forma más ágil con un botón en cada registro, sin necesidad de hacer una búsqueda exacta. Se añadió la visualización de las imágenes/fotos de los bienes por registro de forma individual. Nueva sección "Catálogo de Bienes" para usuarios Prestamistas. Nuevas animaciones al listar bienes en "Nuevo Préstamo" para usuarios Prestamistas, y cambios en el backend en "Insertar Bien" para Administradores se adjunte o no una imagen. Corrección de errores menores (ESTABLE).

v1.1.3 - Optimización de código en módulos para usuarios Administradores. Se añadió la posibilidad de dar de baja bienes siempre y cuando no estén prestados, y a su vez se pueden ver dichos registros aislados para auditorías. Arreglo en consultas del backend, y actualización del esquema de la base de la base de datos. Correcciones menores en validaciones para usuarios Prestamistas (ESTABLE - PRODUCCIÓN).

v1.1.4 - Se añadió la posibilidad de volcar de forma masiva datos para inventario destinado para usuarios Prestamistas (requerimiento adicional). Se incorporó una revisión para imágenes de bienes en el caso que se ingresen de forma manual en el directorio 'imgBienes' (requerimiento adicional). Nueva variable de configuración añadida en la cual se especifica el área del laboratorio. Corrección de detalles menores en el backend (ESTABLE - PRODUCCIÓN).
